Create a modern responsive website for a student election polling platform.

Project name: UPC Student Election Poll Platform.

Purpose:
Allow students of Université Protestante au Congo (UPC) to participate in an election poll and view results.

Pages required:

1. Home Page
- Title: UPC Election Poll 2026
- Short description explaining the platform
- Button: "Participate in the Poll"

2. Faculty Selection Page
Allow students to select their faculty:
- FASE (Economics)
- Law
- Medicine
- Informatics (FASI)
- Theology

3. Candidate Page
Display candidates according to the selected faculty.
Each candidate should appear inside a card with:
- photo placeholder
- name
- vote button

4. Voting System
When a student clicks vote:
- show confirmation message
- store vote
- prevent multiple votes

5. Results Page
Display poll results using:
- bar charts
- percentages
- total votes

Design requirements:
- modern UI
- card-based layout
- smooth animations
- responsive mobile design

Color palette:
Primary: #1E3A8A
Secondary: #3B82F6
Accent: #F59E0B
Background: #F8FAFC
Text: #1F2937
Success: #10B981

Use:
HTML
CSS
JavaScript

Optional:
Chart.js for statistics.

Make the interface elegant, professional, and suitable for a university election platform.
